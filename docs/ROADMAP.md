# Minux 路线图

## 目标

1. 在 RISC-V 64 上实现一个结构完整的宏内核，包括进程、虚拟内存、VFS、设备驱动和系统调用。
2. 子系统划分与核心抽象和 Linux 保持对应，使每个模块都能与 Linux 的实现直接比较。
3. 兼容 Linux RISC-V 系统调用 ABI，最终运行未经修改的 musl 静态链接程序（以 BusyBox 为验收目标）。

## 当前范围之外

- 完整的 POSIX 或 Linux 兼容性：只实现运行目标用户程序所需的子集
- QEMU `virt` 以外的硬件平台
- 动态链接、图形界面

## 设计原则

- **架构隔离**：硬件相关代码限定在 `arch/riscv/`，通用子系统不直接依赖具体架构。
- **接口对齐 Linux**：数据结构、函数命名和系统调用编号尽量与 Linux 一致，偏离时在设计文档中说明原因。
- **先正确，后优化**：每个子系统先给出最简可用的实现，接口稳定后再逐步替换为更完善的算法。
- **可调试性**：在功能之前优先建设日志、断言、栈回溯和启动自检。

## 里程碑

每个里程碑完成后打对应的 git 标签。

| 版本 | 里程碑 | 范围 | 完成标准 | 状态 |
|---|---|---|---|---|
| v0.0 | 引导 | 交叉构建系统、链接脚本、入口汇编、SBI 调用封装 | 从 OpenSBI 进入 `start_kernel`，输出启动信息并正常关机 | ✅ 完成 |
| v0.1 | 内核基础设施 | `printk`/`panic`、`lib/string`、`list_head`、FDT 解析 | 启动时输出 hart 信息与物理内存布局 | 计划中 |
| v0.2 | 异常与中断 | trap 入口与上下文保存、异常分发、定时器中断、PLIC、UART 中断驱动 | 周期性时钟中断；串口输入经中断回显 | 计划中 |
| v0.3 | 物理内存管理 | 页帧分配器（buddy）、`kmalloc`（slab 简化实现） | 分配器启动自检通过，内存统计准确 | 计划中 |
| v0.4 | 虚拟内存 | Sv39 页表、高地址内核映射、`mm_struct`/`vm_area_struct` | 启用分页后内核正常运行；非法访问被捕获并报告 | 计划中 |
| v0.5 | 进程与调度 | `task_struct`、上下文切换、内核线程、抢占式调度、自旋锁、等待队列 | 多个内核线程在时钟驱动下抢占运行 | 计划中 |
| v0.6 | 用户态与系统调用 | 系统调用入口（Linux ABI）、ELF 加载、`fork`（COW）/`execve`/`wait4`/`exit`、缺页处理 | `/init` 在用户态运行并成功创建子进程 | 计划中 |
| v0.7 | 文件系统 | VFS、initramfs、文件描述符、管道、virtio-blk、块缓存、ext2、设备文件 | 从 ext2 磁盘镜像加载并执行程序 | 计划中 |
| v0.8 | 用户环境 | tty 与行规程、信号、`mmap` 等系统调用、musl 用户程序 | BusyBox shell 运行，管道与重定向可用 | 计划中 |
| v1.0 | 稳定版本 | 回归测试、文档完善、接口清理 | 全部里程碑功能稳定，测试通过 | 计划中 |

## v1.0 之后的方向

- SMP 多核支持（每 CPU 运行队列、核间中断）
- procfs、sysfs
- 网络：virtio-net 与 TCP/IP 协议栈
- 页缓存、页面回收与 swap
- 可加载内核模块

## 文档约定

各子系统的设计文档放在 `docs/` 下，内容包括数据结构、关键流程、与 Linux 实现的对照，以及取舍说明。
